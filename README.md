# Footwear Sales Analysis & Forecasting (Power BI)

An interactive and insightful **Power BI project** built to analyze **Footwear Sales**, including KPIs, brand/category performance, city-wise insights, and a **15-day sales forecasting model** using time-series analytics.

This repository contains:
- 📊 **Footwear Sales Dashboard**
- 📈 **15-Day Sales Forecasting Dashboard**
- 📁 CSV datasets
- 📘 DAX measures & Power Query transformations
- 🖼️ Screenshots of the dashboards

---

## 🚀 Project Overview

This Power BI solution provides a complete analytical view of footwear sales data.  
It includes:

### ✔ KPI Insights  
- Total Sales  
- Total Profit  
- Quantity Sold  
- Profit Margin  

### ✔ Category & Brand Analysis  
- Flats, Sandals, Sneakers, Heels, Boots  
- Brand performance (Paragon, Bata, Nike, Adidas, Puma, etc.)  

### ✔ City-wise Analysis  
- Delhi  
- Mumbai  
- Pune  
- Haryana  
- Includes **map visual**  

### ✔ Time-Series Insights  
- Monthly sales trends  
- 15-day forecasting with confidence intervals  

### ✔ Interactive Features  
- Slicers (City, Brand, Category, Size)  
- Drill-through  
- Dynamic visuals
